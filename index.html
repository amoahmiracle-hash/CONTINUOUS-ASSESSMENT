School & Term

School Logo / Crest

Upload your school's crest or logo. It is printed at the top of every report card, faintly behind the scores table, and on the CA sheets and records. A PNG with a transparent background looks best; large pictures are shrunk automatically.

Head Teacher's Signature

Upload this once and it will be stamped automatically on every report card — no need to sign each one by hand. A photo of your signature on plain paper, cropped fairly close, works fine.

Final Mark Weighting

How the termly final mark is split between Continuous Assessment and the End-of-Term Exam. The two should add up to 100, so that Class Score + Exam Score = Total Score out of 100 on every report card.

Classes

Set each class's level to get the right report card title, subject suggestions, and grading bands (Primary bands for KG/Lower/Upper Primary, JHS bands for JHS).

Subjects

Add every subject taught anywhere in the school here, then open a class above to tick which subjects apply to it.

Learners

Bulk add (paste one name per line)

Continuous Assessment Components

The types of CA scores teachers log day to day (Exercises, Homework, Class Tests, etc.), and how much each counts toward the CA score. Weights should total 100%. Sheet columns is how many boxes of that type are printed on the blank CA sheets for teachers (e.g. 4 Class Exercises).

Grading Bands — Primary (KG, Lower & Upper Primary)

Used for the Remarks column on report cards for these levels. Edit freely.

Grading Bands — JHS

Used for the Remarks column on report cards for JHS classes.

Backup & Restore

How the whole school uses this: set everything up here first (classes, subjects, learners, components, grading), then export a Setup file and share it with each teacher's copy of this app. Teachers log daily entries on their own device, then send their file back to you to merge in.

Log Scores

Entry History

Everything logged so far for the selected class & subject this term. Edit or delete a row to correct a mistake.

CA Sheets for Teachers

Print a blank continuous-assessment sheet for each class and subject. Teachers fill it in by hand during the term and hand it to you. You can then type the scores in below, or give teachers the fill-in file (.csv) to complete on a computer and send back for upload. The number of columns per assessment type is set in Setup → Continuous Assessment Components.

In the print window choose Landscape if it is not already selected.

Upload a Filled-in File

Choose the .csv a teacher filled in and returned. You will see a summary and confirm before anything is saved. Re-uploading the same file just updates the same scores — nothing is duplicated.

Type in Scores from a Filled Paper Sheet

Pick a class and one subject above, then copy the scores across exactly as they appear on the sheet. Enter the “Out of” mark at the top of each column. Press Enter to move down a column.

Continuous Assessment Records

A printable record of every score logged, for your files. Choose the full record for one subject, a short summary, or a master sheet showing every subject for the whole class.

Exam Scores

Attendance & Remarks

One row per learner — filled once per term, printed straight onto the report card. Conduct, Attitude, Interest and Teacher's Remark have suggested options (start typing or click the field to see them) — or type your own.

Generate Report Cards

Each card is a single A5 page with a 0.5 cm margin on every side. In the print window choose paper size A5, scale 100% (not “fit to page”), and turn Headers and footers off. To save as PDF, choose “Save as PDF” as the printer.
